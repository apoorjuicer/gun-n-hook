# Gun N Hook: 2D Action Platformer in C

A 2D platformer with a grappling hook and guns: three levels and a boss
fight. 5-person team, 1 trimester (Fall 2024), DigiPen Institute of
Technology Singapore.

## My part (enemy programmer)
- **Enemy system**: created the enemy module (enemy.c/h) with melee and
  ranged enemies, including facing direction and ranged attacks.
- **Ranged combat**: bullet damage for ranged enemies through the shared
  collision library.
- **Boss level**: restructured the boss level's state and wired enemies
  into it.
- **Shared data**: defined and documented the game's shared structs
  (structs.h), and merged the enemy branch into main.
